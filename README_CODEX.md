# Запуск проекта в Codex

1. Распакуйте проект в отдельную папку.
2. Откройте эту папку или Git-репозиторий в Codex.
3. Установите зависимости:

```bash
npm ci
```

4. Проверьте структуру и сборку:

```bash
npm run lint:project
npm run build
```

5. Для локальной разработки:

```bash
npm run dev
```

6. Первая безопасная команда для Codex:

```text
Прочитай AGENTS.md и CODEX_TASK.md. Выполни только этап 1 из CODEX_TASK.md: изучи проект, перечисли связанные файлы, предложи минимальный план доработки категории «Разработка». Код пока не изменяй.
```

## Важно

В архиве находится только исходная Gulp-вёрстка. Для переноса изменений на действующий сайт нужно добавить в отдельную ветку или репозиторий исходники текущей темы WordPress: шаблоны PHP, `functions.php`, ACF-регистрацию или `acf-json`, исходные стили и скрипты темы.

Не добавляйте в репозиторий весь WordPress, базу данных, `uploads`, кэш, резервные копии и секреты. Для работы достаточно темы и, при наличии, собственного плагина с типами записей или ACF-полями.
